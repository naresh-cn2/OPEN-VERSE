# Build & Release Automation Guide

This guide details how OPEN-VERSE compiles production binaries, signs updater payloads, generates release manifests, and distributes updates across all supported platforms.

---

## 1. Automated Release Pipelines

OPEN-VERSE utilizes GitHub Actions for continuous integration and automated releases:

| Workflow File | Purpose | Triggers |
| :--- | :--- | :--- |
| `.github/workflows/desktop-release.yml` | Builds signed Windows NSIS installer, `.sig` Minisign signatures, generates `latest.json`, publishes to GitHub releases and rolling `desktop-latest`. | `workflow_dispatch`, tag push (`v*`) |
| `.github/workflows/android-release.yml` | Compiles signed release APK and Android App Bundle (`.aab`), verifies SHA-256, and uploads artifacts. | Tag push (`v*`), `workflow_dispatch` |
| `.github/workflows/unified-release.yml` | Coordinates multi-platform builds, validates checksums, and updates the release portal. | Tag push (`v*`), `workflow_dispatch` |

## 2. Local Production Packaging

### 2.1 Packaging Windows Desktop (NSIS)

1. Ensure the Tauri private key and password are set in your environment:
   ```powershell
   $env:TAURI_SIGNING_PRIVATE_KEY = Get-Content "$env:USERPROFILE\.tauri\openverse.key" -Raw
   $env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD = Get-Content "$env:USERPROFILE\.tauri\openverse.key.password" -Raw
   ```

2. Compile and package the NSIS installer:
   ```powershell
   cd desktop/apps/examples/desktop-app
   bun run build
   bunx tauri build --bundles nsis --config src-tauri/tauri.windows.conf.json
   ```

Outputs:
- Setup installer: `src-tauri/target/release/bundle/nsis/OPEN-VERSE_<version>_x64-setup.exe`
- Signature file: `src-tauri/target/release/bundle/nsis/OPEN-VERSE_<version>_x64-setup.exe.sig`

### 2.2 Packaging Android Release APK

```bash
cd mobile/android
./gradlew assembleRelease
```

Outputs:
- Release APK: `mobile/android/app/build/outputs/apk/release/app-release.apk`
- Calculate SHA-256:
  ```bash
  sha256sum app/build/outputs/apk/release/app-release.apk
  ```

## 3. Release Manifest Generation

The updater manifest `latest.json` is generated by `desktop/apps/examples/desktop-app/scripts/generate-update-manifest.ts`:

```bash
bun run scripts/generate-update-manifest.ts <version> <repo> <tag> "<notes>"
```

### Schema of `latest.json` (Tauri v2 Format)
```json
{
  "version": "v0.2.3",
  "notes": "OPEN-VERSE production release notes...",
  "pub_date": "2026-11-12T16:33:57.388Z",
  "platforms": {
    "windows-x86_64": {
      "signature": "<base64-minisign-signature>",
      "url": "https://github.com/<repo>/releases/download/<tag>/OPEN-VERSE_<version>_x64-setup.exe"
    }
  }
}
```

### Schema of `open-verse-releases.json` (Universal Cross-Platform Format)
Located at `website/public/open-verse-releases.json` and served live at `https://open-verse-website.vercel.app/open-verse-releases.json`:
```json
{
  "version": "0.2.3",
  "releaseDate": "2026-11-12T14:00:00Z",
  "channel": "stable",
  "mandatory": false,
  "platforms": {
    "windows-x86_64": {
      "version": "0.2.3",
      "url": "https://github.com/naresh-cn2/OPEN-VERSE/releases/download/v0.2.3/OPEN-VERSE_0.2.3_x64-setup.exe",
      "sha256": "7d32a4ba94e3b25152356f46e34a439839e6055cc8b4130d0a5fe4065a0e53bc",
      "signature": "..."
    },
    "android": {
      "version": "0.2.3",
      "versionCode": 5,
      "url": "https://open-verse-website.vercel.app/open-verse-mobile.apk",
      "sha256": "950aba4b9e02d059e53415996c65a70f13ebf4da9780078b5759242ccfe675a7",
      "minSdk": 24
    }
  }
}
```

## 4. Release Checklist

1. [ ] Increment version in `tauri.conf.json`, `package.json`, and `build.gradle.kts`.
2. [ ] Increment `versionCode` monotonically in Android `build.gradle.kts`.
3. [ ] Run `bun run tests/e2e-cross-device-updater-repair.ts`.
4. [ ] Run `bun run tests/e2e-android-auto-update-lifecycle.ts`.
5. [ ] Update `CHANGELOG.md`.
6. [ ] Tag git commit: `git tag vX.Y.Z && git push origin vX.Y.Z`.
7. [ ] Verify GitHub Actions workflows complete.
8. [ ] Verify rolling `desktop-latest/latest.json` reflects the new version.
9. [ ] Verify Vercel website deployment and download center hashes.
